## 任务 B：MetaCaster-adapted 与真实训练数据池对照

原文：[EMNLP 2026](https://aclanthology.org/2026.emnlp-main.2511/)、[arXiv](https://arxiv.org/abs/2608.23473)。[官方代码](https://github.com/D2I-Group/metacaster)，固定提交 `6c82243249485c61dea4fa80e5cc83f87b5e434a`，服务器 vendor 位于 `/mnt/data/ats_resources/vendor/MetaCaster/source`。禁止修改 vendor；MIT 许可保留在 vendor。

实现：`src/agent4ts/baselines/metacaster.py`。

- 复用官方 MGAgent 工具循环、router、HPAgent 已训练好的 regime-aware skill；不在测试任务上重新训练 HPAgent。
- 原版技能的 Python 代码预置供 MGAgent 调用；生成后由宿主独立再次运行原版 `validate_generated`，不能相信 agent 自报 passed。
- agent 只能读训练支持样本与公开变量/时间语义；没有 search/confirm/test 文件挂载。任意生成代码在 bwrap 隔离环境运行，无网络、GPU、凭据、项目或原始数据目录访问。
- 不规则数据仅在生成端变成 64 点历史 + 16 点未来的稠密窗口；历史和训练标签分别插值，禁止跨 cutoff 插值。各通道除以 train-fitted 标准差（不减均值，保留零结构），避免不同单位量级支配官方 global zero_eps；生成后逆变换回原单位。缺测通道用训练均值/历史末值补齐生成输入；回转训练样本时继承真实支持样本的观测掩码、标签掩码、时间位置，不把缺失标签变为实测标签。
- FTAgent 适配为项目共同的 12 模型池，规范默认超参数；按 search normalized MAE 排序、confirm 选 top3 中最佳、test 仅评估最终模型。复用已训练模型，最终部署不含 LLM。
- 与原文的 LT-Lib 20/23 模型、验证 MSE、原始规则时序协议不同，必须标记 **MetaCaster-adapted**，不能声称原文结果复现。
