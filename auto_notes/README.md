# 自动化任务交接目录

供服务器管理员执行、监控、恢复和验收 ATS 自动化任务。文件内容是交接说明，不会自行创建定时任务或启动进程。

## 命名和维护

- 任务文件使用 `YYYY-MM-DD_短名.md`，日期按 `Asia/Shanghai`，短名建议 2–8 个小写字母，例如 `2026-11-07_ats.md`。
- 一份文件对应一项可独立交接的任务；有依赖的任务明确写出执行顺序。
- 每份任务包含：目标、状态及核对时间、主机与目录、资源限制、执行命令、输出位置、恢复规则和验收条件。
- 状态使用：待执行、运行中、待排查、受阻、已验收。只有验收通过才能写“已验收”。
- 后续新增自动化工作时先建任务文件，执行后补充时间、退出状态、结果路径和未解决问题。
- 不写密钥、令牌、患者数据或完整环境变量；只记录私密配置文件的位置。
- 不因文档里有启动命令就重复启动；先检查现有进程。
